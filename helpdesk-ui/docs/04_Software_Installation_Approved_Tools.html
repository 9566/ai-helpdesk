📦 Software Installation & Approved Tools List

⏱ SLA & Expectations: Auto-approved software installs instantly. Paid software or unapproved tools require manager/security approval, which takes 2–4 business days.

How to Install Software

  1. Open the "Acme Self-Service Software Center" application installed on your computer.
  2. Search for the software you need.
  3. If the software is Auto-Approved (see list below), click "Install" immediately.
  4. If the software is listed but says "Request License", click the button to trigger an approval workflow to your manager (for paid tools like Adobe Creative Cloud).
  5. If the software is NOT listed in the Software Center, it is unapproved and requires a ticket.

How to Uninstall Software

  1. Open the "Acme Self-Service Software Center".
  2. Go to the "Installed" tab.
  3. Find the software you want to remove and click "Uninstall".
  4. If the software has a paid license, the license will be automatically reclaimed and can be reassigned to another employee.
⚠️ Prohibited Software: The following types of software are strictly prohibited on company devices and will be automatically blocked:
  • Torrent clients (e.g., BitTorrent, uTorrent)
  • Personal VPN services (e.g., NordVPN, ExpressVPN — use the company VPN only)
  • Cryptocurrency mining software
  • Remote desktop tools not approved by IT (e.g., TeamViewer, AnyDesk)

Troubleshooting / Common Errors

Problem: Prompted for an "Administrator Password" when trying to install software from the internet.

Solution: Employees do not have local admin rights. You must use the "Acme Self-Service Software Center" to install software. Do not attempt to install from external websites.


Problem: The auto-approved software fails to install or gets stuck at "Downloading".

Solution: Ensure you are connected to the corporate VPN (if working remotely), reboot your computer, and try clicking install again. If it still fails, check that you have at least 5 GB of free disk space.


Problem: A previously installed program stopped working or is asking to "reactivate".

Solution: Your license may have expired. Open the Self-Service Center, go to the "Installed" tab, and check the license status. If it says "Expired", click "Renew License" to trigger a new approval request.

🚨 Escalation Rule: If you absolutely require a piece of software that is not listed in the Software Center for your job, submit an IT Ticket under the category "Software" with a detailed business justification. The Security team will review it and add it to the catalog if approved.
